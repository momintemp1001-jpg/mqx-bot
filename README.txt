M-Qxbroker AI Bot - Android project
1) Upload this whole folder to a new GitHub repository (keep the .github folder).
2) GitHub -> Actions -> "Build APK" -> open the finished run -> Artifacts -> download M-Qxbroker-AI-Bot-apk.
3) Unzip, copy app-debug.apk to your phone, allow "install unknown apps", install, open.
(Or open the folder in Android Studio and press Run.)
